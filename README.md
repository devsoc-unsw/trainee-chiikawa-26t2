## Getting Started

Learnten is made up of a frontend and a backend structured as a monorepo. We will be using [pnpm](https://pnpm.io/) as the package manager. To install, start by cloning the repo. If you have permission to push changes, make sure you've set up [SSH keys](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent) on your account. You can then clone the repo with `git clone git@github.com:devsoc-unsw/trainee-chiikawa-26t2.git`.

### Frontend
Navigate into the frontend with `cd frontend` and then run `pnpm i` to install packages. To start the development server, run `pnpm run dev`.

### Backend
Navigate into the backend with `cd backend` and then run `pnpm i` to install packages. To start the backend server, run `pnpm run dev`.
